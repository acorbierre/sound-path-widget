# sound-path-widget

Widget « Chemin du son » partagé entre Qualipo (Superkaiser) et Atlas.

- `src/model.ts` : étapes, états et cas de diagnostic
- `src/cases.ts` : un diagnostic par cas
- `src/wording.ts` : libellés et messages
- `src/SoundPathWidget.tsx` + `sound-path-widget.css` : composant (CSS pur, variables `--spw-*`)
